# Spuds pre-launch flags

- [ ] **Welcome popup frequency.** In the Shopify theme editor, open **Spuds welcome popup → Pre-launch flags** and enable **Hide for 7 days after dismissal**. Save the setting, close the popup in a fresh browser session, and reload an eligible page. It should stay hidden. During preview testing the setting is off, so closing and reloading restarts the five-second timer.
